Should the agent chime in?

A proactive agent normally runs a full LLM turn on every message just to decide whether to speak. Here a small decision model decides first:

  1. Microsoft-Decision-1.1 reads the conversation and answers two questions: how should the agent contribute? and how valuable would a reply be?
  2. Only if both answers say "reply" does the chat model write one.
